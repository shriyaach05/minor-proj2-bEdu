# Notion landing page
A simple responsive landing page built for minor project 02 
It is built using HTML and CSS with Flexbox and CSS Grid. Media queries are used to make the page work well on mobile, tablet, and desktop screens.

## Sections
- Navbar
- About
- Features
- Benefits
- Reviews
- Pricing
- Footer

## Files

- `index.html` : main page
- `notionlogo.png` : logo
- `template1.png`, `template2.png`, `template3.png` : preview images
